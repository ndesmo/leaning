REDUCTION (|B| = p prime, p in {5, 13}; same as the pass-2 |B| = 3 argument)
- |G| = 195p. H = p-Sylow of G, |H| = p^2; G = H x K, |K| = 195/p (39 or 15), squarefree so K cyclic.
- t = |K| is coprime to p = |B|, so by coprime dilation (Tijdeman; roles of A,B swapped, as in pass 2)
  A (+) tB = G. tB lies in H (t kills K), and |tB| = p since the sum is direct.
  So WLOG B in H, 0 in B. Then A (+) B = G iff for every k in K the fibre A_k = {h : (h,k) in A}
  satisfies A_k (+) B = H (so |A_k| = p).
- Rédei (1965): in a factorisation of a finite abelian group into factors of prime size each
  containing 0, some factor is a subgroup. Here A_k - a0 (+) B = H with |A_k| = |B| = p.
  If B is a subgroup -> multiplicative case (G/B of order 195, phi injective on [195]) -> impossible (CCP).
  So B is not a subgroup, and every complement of B in H is a translate of a subgroup of order p.
  Verified exhaustively for p = 5 by tiles_p2.py (out/m5_tile_classes.txt).
- H = Z_p x Z_p: every fibre is a coset of a line L that B is a transversal of ("allowed" lines).
  Pick any two distinct b, b' in B: the line L3 through b - b' is not allowed. L3 meets every allowed
  line in 0, so every fibre A_k satisfies A_k (+) L3 = H, so A (+) L3 = G with L3 a subgroup:
  multiplicative case, impossible by CCP.  => Z_p^2 closed by theory (for p = 5 and p = 13).
- H = Z_{p^2}: the only subgroup of order p is P = pZ_{p^2}, so every non-subgroup tile B has
  exactly the cosets of P as complements, and the condition is the same for all such B:
  "every fibre A_k is one full coset of P". One search per p (gtile6 mode=coset).
